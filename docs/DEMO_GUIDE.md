# Executive demo guide

## Recommended sequence

1. Start in the baseline chapter and introduce the synchronized signal/anatomy view.
2. Press play and pause near 9.6 seconds when the left temporal onset is highlighted.
3. Switch to the superior camera to expose the relationship between cortical and deep structures.
4. Continue through 13.4 seconds to demonstrate network propagation.
5. Use the anatomy layer controls to isolate limbic structures and deep nuclei.

## Framing

Describe the experience as a visualization and communication layer for EEG review. The current signal is deterministic synthetic data and the activity mapping is a narrative model, not an inference from a validated diagnostic algorithm.

## Presentation checklist

- Use a Chromium-based browser with hardware acceleration enabled.
- Prefer a 16:9 display at 1440×900 or higher.
- Load the page once before the meeting so the pinned CDN modules are cached.
- Enter presentation mode and confirm the 3D model has finished loading.
- Keep a screen recording available as a fallback for restricted networks.
